# Карта файлов

## Главные файлы

`theatre-wishlist.html`

Основная страница театрального wishlist.

`index.html`

Стартовая страница для Replit. Она автоматически открывает `theatre-wishlist.html`.

`main.py`

Маленький сервер для Replit. Запускает сайт на порту `3000`.

`.replit`

Команда запуска Replit:

```bash
python3 main.py
```

`.gitignore`

Исключает служебные файлы из Git.

## Документы

`README.md`

Короткое описание проекта.

`DEPLOY.md`

Пошаговая инструкция для GitHub Desktop и Replit.

`PROJECT_FILES.md`

Эта карта файлов.

`N8N_AUTOMATION.md`

Документация по n8n-сценарию: Telegram-бот, AI Agent, проверка дублей, Supabase Insert и ответы в Telegram.
